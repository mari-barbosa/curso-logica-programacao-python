**Nesta aula, você vai aprender a repetir tarefas automaticamente com o uso de laços e controlar a execução do programa por condições.**

## 📚 Objetivos da aula

- Entender o que são laços de repetição.
- Usar o while para repetir trechos de código.
- Controlar a condição de parada.
- Automatizar tarefas repetitivas.

## 🧠 O que você vai aprender

### 1. Conceitos principais

- Repetição e automação;
- Estrutura while;
- Condição de parada;
- Contadores e acumuladores;
- Exercícios com loops simples.

### 2. Aplicações práticas

- Executar blocos repetidamente;
- Criar programas que continuam até uma condição mudar;
- Contar eventos e processar múltiplos dados;
- Repetir ações com menos código;
