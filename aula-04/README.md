**Nesta aula, você vai aprender a tomar decisões no código usando condicionais e a lógica por trás de programas que respondem a diferentes situações.**

## 📚 Objetivos da aula

- Entender o que são estruturas condicionais.
- Aprender a usar if, elif e else.
- Comparar valores e tomar decisões com base em condições.
- Resolver exercícios com lógica condicional.

## 🧠 O que você vai aprender

### 1. Conceitos principais

- Condições lógicas;
- Comparações e operadores booleanos;
- Estruturas if/else;
- Tomada de decisão em programas reais;
- Exercícios de lógica condicional.

### 2. Aplicações práticas

- Verificar se uma condição é verdadeira;
- Executar blocos de código diferentes;
- Criar regras de negócio simples;
- Tomar decisões de acordo com dados do usuário;
