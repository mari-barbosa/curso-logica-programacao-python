Nesta aula, você vai aprender a repetir instruções por um número definido de vezes usando o laço for.

## 📚 Objetivos da aula

- Compreender a estrutura for em Python.
- Conhecer a ideia de iterar sobre sequências.
- Usar range( ) e listas em repetições.
- Resolver exercícios com execução controlada.

## 🧠 O que você vai aprender

### 1. Conceitos principais

- Laço for;
- Range( );
- Iterações sobre listas e strings;
- Repetição com limite definido;
- Práticas com loops controlados.

### 2. Aplicações práticas

- Repetir trechos de código um número fixo de vezes;
- Percorrer elementos de uma sequência;
- Automatizar tarefas em blocos pequenos;
- Aplicar lógica em coleções de dados;
