**Nesta aula, você vai aprender a guardar informações em variáveis e entender como o Python trabalha com diferentes tipos de dados.**

## 📚 Objetivos da aula

- Entender o que são variáveis e para que servem.
- Aprender a guardar valores em memória.
- Conhecer os tipos de dados mais comuns.
- Praticar a atribuição e o uso de variáveis em programas simples.

## 🧠 O que você vai aprender

### 1. Conceitos principais

- O que é uma variável;
- Nomeação de variáveis;
- Tipos de dados como texto, números e booleanos;
- Atribuição e manipulação de valores;
- Exercícios para fixar esse conceito.

### 2. Aplicações práticas

- Criar e reutilizar variáveis;
- Guardar valores em memória;
- Combinar dados em cálculos simples;
- Entender como a informação flui no programa;
