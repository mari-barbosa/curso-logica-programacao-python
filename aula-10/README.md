## 🧠 O que você vai aprender

### 1. Projeto final: Gerenciador de Tarefas

Neste projeto, você vai criar um programa para:

- Adicionar tarefas;
- Listar tarefas;
- Remover tarefas;
- Manter o menu ativo até a pessoa decidir sair.

### 2. Estrutura do programa

O projeto será organizado em partes:

- Menu de opções;
- Loop principal;
- Funções auxiliares;
- Lista para armazenar tarefas;
- Lógica para remover itens da lista.

### 3. Reuso de código

Uma parte importante desta aula é aprender a separar responsabilidades em funções. Isso facilita:

- Leitura do código;
- Manutenção;
- Reutilização;
- Crganização do pensamento de programação.

## 🧪 Conteúdo do notebook

O notebook da aula 10 inclui:

- Explicação do projeto final;
- Requisitos do sistema;
- Estrutura do menu interativo;
- Criação das funções `adicionar_tarefas()`, `listar_tarefas()` e `remover_tarefas()`;
- Montagem do loop principal;
- Integração da lógica inteira em um único programa;
- Desafios extras para aprofundar o projeto.

## 🏋️ Funcionalidades do projeto

O programa deve permitir:

- Exibir um menu com opções ativas;
- Manter o programa em execução até o usuário sair;
- Armazenar tarefas em uma lista;
- Separar cada ação em funções específicas;
- Oferecer uma base para evoluções futuras.
