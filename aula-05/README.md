**Nesta aula, você vai ampliar o uso de decisões em Python e aprender a lidar com múltiplas condições em um mesmo programa.**

## 📚 Objetivos da aula

- Aplicar condicionais múltiplas de forma organizada.
- Entender o uso de elif em cenários mais complexos.
- Estruturar lógica com mais de uma regra.
- Resolver problemas com diferentes caminhos de execução.

## 🧠 O que você vai aprender

### 1. Conceitos principais

- Condições encadeadas;
- Elif e decisões em cascata;
- Aninhamento de condicionais;
- Programas com múltiplas regras;
- Prática de lógica de decisão.

### 2. Aplicações práticas

- Testar múltiplas possibilidades;
- Criar menu de opções com condicionais;
- Classificar entradas diferentes;
- Organizar a lógica do programa com clareza;
