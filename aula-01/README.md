## 🧠 O que você vai aprender

### 1. O que é programação?

Programação é a criação de instruções que dizem ao computador como realizar uma tarefa. Essas instruções precisam seguir uma sequência lógica para que o resultado desejado seja alcançado.

### 2. O que é um algoritmo?

Um algoritmo é uma sequência de passos bem definidos para resolver um problema ou atingir um objetivo.

Exemplo simples: preparar um sanduíche, seguir receitas ou realizar tarefas do dia a dia.

### 3. Por que Python?

Python é uma linguagem amigável para iniciantes porque:

- tem uma sintaxe simples e legível;
- é usada em diversas áreas, como automação, ciência de dados, IA, web e scripts;
- é uma excelente porta de entrada para a lógica de programação;
- permite aprender conceitos fundamentais sem se perder em regras complexas.

### 4. Jupyter Notebook e Google Colab

Nesta aula, você vai conhecer o ambiente de desenvolvimento usado ao longo do curso:

- Jupyter Notebook: ferramenta para criar documentos com código, explicações e resultados.
- Google Colab: versão gratuita e online do Jupyter, ideal para quem quer começar sem instalar nada.

### 5. Primeiro código em Python

Você vai aprender a usar a função `print()`, que permite mostrar mensagens na tela.

```python
print("Olá, mundo!")
```
