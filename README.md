<u>**Aprenda Python do zero com um caminho prático, direto e gratuito.**</u>

Este repositório reúne notebooks, exercícios e conteúdos teóricos organizados em aulas sequenciais para quem quer começar desde os fundamentos da programação.

## 🎯 O que você vai aprender

- Lógica de programação e algoritmos;
- Conceitos básicos de Python;
- Uso de variáveis, condicionais, loops e funções;
- Resolução de exercícios práticos;
- Construção de um projeto final no fim do curso.

## 🚀 Como estudar

1. Comece pela Aula 01 e siga a ordem das aulas.
2. Abra os notebooks no Jupyter ou no Google Colab.
3. Tente resolver os exercícios antes de olhar a resposta.
4. Revise os exemplos com frequência para fixar os conceitos.
